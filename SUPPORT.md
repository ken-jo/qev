# Support QEV

If QEV is useful to you, [star the repository](https://github.com/ken-jo/qev), share a
reproducible use case, or help improve the documentation and evaluation coverage.

The SDK and playground are available without starring or donating. The optional
`qev star --open` command opens the repository; you choose whether to star it while
signed in to GitHub.

You can support ongoing maintenance through [GitHub Sponsors](https://github.com/sponsors/ken-jo).
Use the repository's Sponsor button, the playground's GitHub Sponsors link, or
`qev support --open` to visit the page. Sponsorship is optional and does not unlock
additional model capabilities.
